FAQs

All emulators
Are games or Nintendo BIOS files included?+

No. Import your own compatible game files. Koki uses an open BIOS replacement for direct DS boot.

Is this a stable release?+

This is an experimental public preview. Some games may have visual, audio or performance problems. Physical Android testing and broad compatibility checks are still pending.

Can I use earlier checkpoints?+

Versions 0.1.1 and 0.1.2 share the same engine and checkpoint format. If you used the earlier 0.1.0 private preview, its checkpoints cannot be loaded by this engine. Compatible .sav files carry forward; save inside the game and export a backup in the old app before migrating.

Does it support DSi or multiplayer?+

This preview supports Nintendo DS games. DSi, wireless multiplayer, microphone and camera features are not available.
