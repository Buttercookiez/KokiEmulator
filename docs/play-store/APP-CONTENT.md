## App access — copy-ready instructions

All app features are available without signing in. There is no account, password, subscription, location restriction or paid unlock.

The first launch displays an empty local library. Reviewers can explore Settings, Colors and privacy/support without a game. To test emulation, choose Add games and import a GBA file that you are authorized to use. No commercial game files or Nintendo BIOS are included or downloaded. A small original diagnostic ROM is publicly available at https://koki-emulator.vercel.app/reviewer/koki-diagnostic.gba. Download that file, then choose Add games and import it. The green screen means the core is running; holding A changes it to red, and held D-pad directions light white markers along the top. It also writes a test in-game save. This is a diagnostic, not a full game. It is not bundled in the app and contains no commercial game or Nintendo BIOS data.

Source: https://github.com/Buttercookiez/KokiEmulator/blob/main/scripts/make-diagnostic-rom.mjs
